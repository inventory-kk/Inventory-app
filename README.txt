# Inventory Management Web V1

Web inventory app based on the provided Excel structure.

Files:
- index.html — main web app
- manifest.webmanifest — installable web-app metadata
- sw.js — offline cache

The app contains:
1. Dashboard
2. Inventory Daily
3. Barang OUT
4. Barang IN
5. Stock Awal
6. Form Estimasi Order
7. SO Monthly

Master item order, UOM, opening stock, expiry, and embedded product images are based on the Excel file.
